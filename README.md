# FUROSITY — Tech Portfolio Agency

A modern tech portfolio agency web application built with **Next.js**, **Tailwind CSS**, and **Lucide React**.

## 🚀 Getting Started

To run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## 📦 Build for Production

```bash
npm run build
npm run start
```

## 🛠️ Stack & Features

- **Next.js 16 (App Router)** & **React 19**
- **Tailwind CSS** with 2D dark modern tech aesthetics and subtle ambient grids
- **Lucide React** icon library
- **Navbar Component**: Responsive navigation with brand identity and mobile drawer toggle
- **Hero Section**:
  - Live pulse badge: *"IDEAS TODAY FOR A BRIGHTER TOMORROW"*
  - Headline: *"Curiosity Builds What's Next."* with multi-stop gradient highlights
  - Subtitle: *"Furosity builds modern web products, AI solutions and automation tools that turn ideas into real-world impact."*
  - Dual action CTAs: *"Let's Build Together"* and *"Watch Our Story"*
  - Stats row: *10+ Projects Delivered*, *100% Client Satisfaction*, *4 Passionate Developers*
  - 2D Vector Tech Canvas: Interactive architecture pipeline, telemetry metric chart, and active feature badges
